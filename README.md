# X-Clash-
S1 map 474 Version for ZSW. 

Disclaimer: 
This is just a project only for personal use and shared internally among ZSW riceball members. 
Source code was copied from online of unknown author and modifications were made base on that.



How to use:
  - left click = ZSW
  - right click = VRW or other unions (if have)

  - states: unoccupied --> occupied --> abandoned
    (now this is a bit buggy since no checking on union is done, but will not affect final output if using properly)
